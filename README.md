# 🎭 Minigames Hub

**Minigames Hub** is an all-in-one, browser-based web application designed for party games and group social deduction. Built with vanilla JavaScript and Tailwind CSS, it requires no installation, backend server, or build steps.

Play locally by passing a single phone around or connect wirelessly with friends using peer-to-peer online lobbies!

## 🎮 Included Games
* **🎭 Impostor:** Everyone answers a prompt except the impostor, who gets a slightly different question. Spot the outsider!
* **🕵️ Mister White:** Civilians share a word, Undercovers get a similar one, and Mister White gets only a category hint.
* **💬 Who Said That?:** Submit anonymous answers to funny or controversial questions and guess who wrote what.
* **🐺 Werewolf (Lupus in Fabula):** Full narrator-less party game experience with custom roles, automated night phases, secret voting, and victory tracking.

## ✨ Key Features
* **Pass & Play or Online:** Play on a single device or host P2P rooms using PeerJS without creating an account.
* **Bilingual Support:** Full Italian and English localization built-in (more to come!).
* **Flexible Modes:** Automatic question generation (real-time AI in future updates) or Human Game Master (GM) mode.
* **Single File Architecture:** Zero build tools or external servers required, just open the HTML file in any browser!
* **More and More and More!:** First release includes 4 minigames, with many more planned, including originals!
